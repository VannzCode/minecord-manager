# Contributing

Thanks for considering a contribution to Minecord Manager!

1. Open an issue before large changes so the scope can be discussed.
2. Keep changes focused and document new environment variables or commands.
3. Add or update tests when changing protocol parsing or other testable behavior.
4. Run `npm test` and `npm run check` before opening a pull request.
5. Never commit `.env`, tokens, private addresses, or personal data.

Please describe what changed, why it is useful, and how you tested it in your pull request.
